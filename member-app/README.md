# member-app

这是放在 `F:\\work\\quanshidaHT-JAVA` 下的 uni-app 会员端骨架工程。

## 目标

用于承载集运订单系统的会员端，多端统一代码，后续可编译到：
- H5
- 微信小程序
- App

## 当前已落地内容

- uni-app 基础目录结构
- 页面入口配置 `pages.json`
- 基础页面骨架：
  - 会员中心
  - 登录
  - 我的账户
  - 收货地址
  - 运单预报
  - 我的库存
  - 集运申请
  - 我的订单
- 简易请求层 `utils/request.js`
- 会员端 API 占位文件 `api/member.js`

## 建议后续开发顺序

1. 后端新增会员认证与会员业务接口
2. 会员端接登录/鉴权
3. 接地址管理
4. 接运单预报
5. 接库存/认领/问题件
6. 接集运申请
7. 接订单与支付

## 注意

当前骨架主要用于定结构，不包含完整 CLI 运行链路。
建议使用 HBuilderX 打开 `member-app` 目录继续开发，或后续再补全 `@dcloudio` 的 CLI 工具链。
